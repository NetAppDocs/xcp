= activate
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The SMB `activate` command activates the XCP license. Before running this command, verify that the license file is downloaded and copied on the C:\NetApp\XCP directory on the XCP host or client machine. The license can be activated on any number of hosts.

.Syntax
[source,cli]
xcp activate
