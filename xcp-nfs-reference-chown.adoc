= chown
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The XCP NFS `chown` command scans and changes the ownership of all the files for the given directory structure. The `chown` command requires an NFS share or the POSIX path as a variable. XCP chown recursively changes the ownership for a given path. The `chown` command displays the changed user ID (UID) for a file.

.Syntax
[source,cli]
xcp chown -user/-group <user-name/group-name> <source NFS export path>

include::./_include/ref-example-nfs-chown.adoc[]

The following table lists the `chown` parameters and their description.

[cols=2*,options="header"]
|===
| Parameter
| Description
| <<nfs_chown_exclude, chown -exclude <filter>  >> | Excludes the files and directories that match the filter. 
| <<nfs_chown_match, chown -match <filter>  >> | Only processes the files and directories that match the filter.
| <<nfs_chown_group, chown -group <group>  >> | Sets the Linux group ID (GID) at the source.
| <<nfs_chown_user, chown -user <user> >> | Sets the Linux UID at the source.
| <<nfs_chown_user_from, chown -user-from <user_from> >> | Changes the UID.
| <<nfs_chown_group_from, chown -group-from <group_from>  >> | Changes the GID.
| <<nfs_chown_reference, chown -reference <reference> >> | Specifies the referenced file or directory point.
| <<nfs_chown_v,chown -v >> | Reports the output for every object processed.

|===

[[nfs_chown_exclude]]
== chown -exclude <filter>

Use the `-exclude <filter>` parameter with the `chown` command to exclude the files and directories that match the filter. 

.Syntax

[source,cli]
xcp chown -exclude <filter> -user <user_name> <source NFS export path>

include::./_include/ref-example-nfs-chown-exclude.adoc[]

[[nfs_chown_match]]
== chown -match <filter>

Use the `-match <filter>` parameter with the `chown` command to only process the files and directories that match the filter.

.Syntax

[source,cli]
xcp chown -match <filter>  -user <user_name> <source NFS export path>

include::./_include/ref-example-nfs-chown-match.adoc[]
