The SMB `help` command displays a list of commands, command parameters, and a brief description of each. This command is very useful for beginners who are new to XCP.

.Syntax
[source,cli]
xcp --help

Use <command> with `help` to display examples and option details for the specified <command>.

.Syntax

[source,cli]
