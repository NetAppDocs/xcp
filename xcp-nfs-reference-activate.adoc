= activate
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The NFS `activate` command activates the XCP license.

NOTE: Before running this command, verify that the license file is downloaded and copied to the `opt/NetApp/xFiles/xcp/` directory on the XCP server. 

.Syntax

[source,cli]
xcp activate
