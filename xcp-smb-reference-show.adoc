= show
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The SMB `show` command queries the RPC services and NFS exports of one or more storage servers. The command also lists the available services and exports with the used and free capacity of each export, followed by the attributes of the root of each export.

.Syntax
The `show` command requires the host name or IP address of the NFSv3 exported system:
[source,cli]
xcp show \\<IP address or hostname of SMBserver>
