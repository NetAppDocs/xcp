= XCP SMB command reference overview
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The XCP SMB command reference provides examples of the available commands for XCP SMB. Each command has additional parameters that can be used alone or in combination as required.

[NOTE]
====
An XCP command output can be redirected by using the “>” operator, as shown in the following example:
----
C:\xcp>xcp --help > help-output.txt
XCP SMB 1.6; (c) 2020 NetApp, Inc.; Licensed to xxxx xxxx[NetApp Inc] until Mon Dec 31 00:00:00 2029
C:\xcp>
----
====
