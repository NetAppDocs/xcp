= XCP SMB command reference overview
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The XCP SMB command reference provides examples of the available commands for XCP SMB. Each command has additional parameters that you can use alone or in combination, as required.

[NOTE]
====
You can redirect an XCP command output by using the “>” operator, as shown in the following example:
----
C:\xcp>xcp --help > help-output.txt
----
====
