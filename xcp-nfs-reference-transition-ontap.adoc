= How to transition 7-Mode NFSv3 Storage to ONTAP 
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
This section covers the step-by-step procedure for transitioning a source 7-Mode NFSv3 export to an ONTAP system.

NOTE: NetApp assumes that the source 7-Mode NFSv3 volume is exported and mounted on the client system and that XCP is already installed on a Linux system.
