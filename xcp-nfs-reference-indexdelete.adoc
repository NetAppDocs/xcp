= indexdelete
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[lead]
The NFS `indexdelete` command deletes catalog indexes.

.Syntax

[source,cli]
xcp indexdelete

include::./_include/ref-example-nfs-indexdelete.adoc[]

he following table lists the `indexdelete` parameters and their description.

[cols=2*,options="header"]
|===
| Parameter
| Description 
| <<nfs_indexdelete_match, indexdelete -match <filter>  >> | Only processes the files and directories that match the filter.
| <<nfs_indexdelete_loglevel, indexdelete -loglevel <name>  >> | Sets the log level; available levels are INFO, DEBUG (default: INFO).

|===

[[nfs_indexdelete_match]]
== indexdelete -match <filter> 

Use the `-match <filter>` parameter with the `indexdelete` command to only process the files and directories that match the filter.

.Syntax

[source,cli]
xcp indexdelete -match "fnm('S3_index12')"

include::./_include/ref-example-nfs-indexdelete-match.adoc[]

[[nfs_indexdelete_loglevel]]
== indexdelete -loglevel <name>

Use the `-loglevel <name>` parameter with the `indexdelete` command  to set the log level; available levels are INFO, DEBUG. the default level is INFO.

.Syntax

[source,cli]
xcp indexdelete -loglevel DEBUG -match "fnm('test*')"

include::./_include/ref-example-nfs-indexdelete-loglevel.adoc[]
